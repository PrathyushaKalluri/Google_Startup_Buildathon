# Evidence and provenance

## Labels

**LIVE** — actual external provider/transport result.  
**ROLEPLAY** — a real participant acting in a fictional scenario.  
**DOC_SIMULATED** — external response matching provider documentation but not sent over live network.  
**SYNTHETIC_FIXTURE** — invented agency/technician/parts/price records for testing.  
**SECONDARY_SOURCE** — public article/vendor/review/complaint with limitations.  
**VERIFIED_FIELD** — genuine observed real repair evidence.

A role-play message sent over real WhatsApp can be:
- transport = LIVE_WHATSAPP;
- fact source = ROLEPLAY.

These are independent dimensions.
