# /a11y — Accessibility Verification Pass

1. Run Flutter widget & semantics tests across all packages:
   ```bash
   melos run test:a11y
   ```
   (or `flutter test` in `apps/kw_ui`, `apps/console`, `apps/field`, `apps/household`, `apps/brand`).
2. Build web release bundles with semantics enabled and serve via Firebase Hosting emulator (`infra/frontend/firebase.json`).
3. Run Lighthouse accessibility & performance audits (or Chrome DevTools MCP) for each surface (`console`, `field`, `household`, `brand`) and save reports to `docs/design/lighthouse/`.
4. Verify manual WCAG 2.2 AA gates:
   - Keyboard-only navigation & calendar drag alternative
   - Contrast >= 4.5:1 text / 3:1 UI in Light, Dark, High-Contrast
   - 200% text scale with no overflow; 48 dp minimum touch targets
   - Polite live regions for transcript & feed; `en`/`hi`/`te` language tags
5. Fix every serious or critical finding before completing the milestone.
