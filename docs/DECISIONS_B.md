# Part B Architecture & Engineering Decisions (`docs/DECISIONS_B.md`)

- **D-B01 (Input Path Resolution):** The repository holds `SHARED_CONTRACT.md` and `keepwell_design_doc.md` at root and the v0.2 dataset archive at `keepwell/docs_v1/keepwell_sim_dataset_v0.2.zip` instead of `contract/` and `input/`. Part B will not move or duplicate frozen inputs; `mocks/fixtures/build_fixtures.py` auto-resolves `input/dataset/` first and falls back to `keepwell/docs_v1/keepwell_sim_dataset_v0.2.zip` so it works both now and after Integrator merge.
- **D-B02 (State Management):** Standardise on **Riverpod (`flutter_riverpod`)** across all four Flutter apps (`console`, `field`, `household`, `brand`) for clean dependency injection of `kw_client` REST/Firestore/WebSocket providers and deterministic widget/golden testing.
- **D-B03 (Routing):** Use **`go_router`** across all apps to support deep-linked web URLs (`/stage`, `/tickets/:id`, `/v/:token`, `/home/:token`, `/quotes/:token`, `/otp/:token`) with lazy route loading and role-based auth redirects.
- **D-B04 (Material 3 Expressive in Flutter):** Live documentation confirms Flutter's core Material 3 widgets lag slightly behind Jetpack Compose on M3 Expressive spatial/effects springs and shape morphing. `apps/kw_ui` implements M3 Expressive tokens directly using Flutter's `SpringSimulation` (spatial fast/default/slow and effects fast/default springs), expressive shape tokens, split buttons, button groups, and loading indicators, respecting `MediaQuery.disableAnimations` everywhere.
- **D-B05 (Mock Stack Choice):** Implement `mocks/rest` and `mocks/ws` in Python 3 (FastAPI + `uvicorn` + `websockets`) so they run immediately with zero extra toolchain friction, expose `/openapi.json` matching Contract C5, support stateful mutations (`reclassify`, `reassign`, `approve`, `pay-intent`, `sandbox-complete`, `debrief`, `otp`), and support `X-Mock-Fail: <status>` error injection.
- **D-B06 (Data Residency & Endpoints):** All Firebase and REST endpoints default to `asia-south1` (Mumbai) in production config (`infra/frontend/firebase.json`) and local emulators (`localhost:8080` Firestore, `localhost:9099` Auth, `localhost:8081` Mock REST, `ws://localhost:8082/v1/live/call` Mock WS) in development.
- **D-B07 (SDK Prerequisite):** Local machine currently lacks `flutter`, `dart`, `melos`, and `firebase` CLI. Milestone B0 and `mocks/` are built immediately; Flutter SDK + Firebase CLI installation is requested in the implementation plan before compiling and testing `apps/*`.
- **D-B08 (No Third-Party Brand Marks):** The Household WhatsApp simulator uses a calm Material 3 Expressive chat layout labelled `"WhatsApp simulator"` with zero WhatsApp logos or green trade dress (per Section 6.2).
